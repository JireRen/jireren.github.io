    Paper Title Number 5, with math \(E=mc^2\)

    Published in GitHub Journal of Bugs, 2024

    Using MathJax in the description is supported - \(E=mc^2\) - however, the use must be mindful that the default delimiters are $$...$$ and \\[...\\] which differs from the $...$ that is typically expected.
